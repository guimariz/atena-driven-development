# Optional knowledge and specialist sources

The generic distribution is self-contained for ADD installation, planning, local state, preservation and CLI operations. It does not contain the maintainer's vault, personal Stanley/Prometeus profiles, private source transcripts or agent-review staging. It does not implement remote vault lookup, knowledge synchronization, model training or native specialist registration.

When a task needs a source not supplied in the receiving project, report that source as unavailable. Do not invent its contents or claim a role has loaded it. Continue only independent work supported by the supplied inputs, marking assumptions and DRAFT state; leave source-dependent production or acceptance pending. Obtain an approved reference or a separately reviewed optional profile if needed. Do not copy another account's credentials, conversation approvals or private corpus to fill the gap.

Game-specialist templates are portable source contracts, not installed agents. Any optional profile must resolve its actual instructions and reference revisions in the receiving project, have rights/privacy reviewed and preserve project canon. File presence, instruction loading and an observed bounded runtime operation are separate evidence levels. Local tests of the CLI prove none of these client/runtime claims.
