# ADD v0.2 example project

This example contains:

- `.atena/` as the canonical workspace;
- `SPEC-001`, a planned Guided ADD change with one plan approval;
- `SPEC-002`, a truthful post-hoc reconciliation of a Direct Execution change.

Try these interaction styles:

```text
Atena, add a new capability to this example.
```

or intentionally use the fast path:

```text
Add a short troubleshooting section to PROJECT-STATUS.md.
```

After the second form, Atena should offer post-hoc reconciliation.
