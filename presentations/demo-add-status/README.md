# Miniprojeto para demonstração do ADD

Este é um caso didático preparado em 2026-10-07 para o vídeo da SPEC-007. O pedido demonstrado é “acrescente um resumo de status”. O arquivo `PROJECT-STATUS.md` e a evidência são reais neste diretório; a narrativa e o checkpoint apresentados no vídeo são uma simulação instrucional. A autorização efetiva para criar o miniprojeto veio do PLAN-007 do repositório principal, não de uma aprovação independente deste projeto de exemplo.

Antes da mudança, este miniprojeto continha este README e o contrato `.atena/`, sem `PROJECT-STATUS.md`. O estado anterior e o resultado estão documentados em `.atena/evidence/SPEC-001-status-summary/`.

Nenhum registro deste miniprojeto foi promovido a canon. O vault canônico do repositório principal é mostrado separadamente nos slides sobre memória e graph.
